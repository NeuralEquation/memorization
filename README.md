### 使い方と収録範囲

- `index.html`：1問1答、4択、正誤＋訂正・理由、制度比較、時系列、計算。回答前に解説を表示せず、「次へ」で進む。
- [印刷用HTML](print.html) / [A4 PDF](output/pdf/seikei-midterm-202610.pdf)：体系解説、比較表、独自問題と解答解説。HTMLの印刷範囲で解説・問題・解答を分けて印刷可能。
- [180問対応監査](coverage.html) / [CSV](coverage.csv)：完全照合0、訂正論点のみ9、内容未確認171。正答番号だけから要求知識を推測しない。
- [資料・法令の確認状況](sources.html)：授業プリント1〜9の画像確認と、訂正報告・一次資料を根拠にした先行版。授業プリントの細目を全て取り込んだ版ではない。
- プリント10・現在の政党別議席・連立情報は範囲と問題集対応が未確認のため出題保留。過去問は一部ページの形式のみ確認、音声は未聴取。
- 間違いの再出題を新しい問題に交ぜ、未習得・重要度A/B・単元で絞り込める。学習履歴はこのブラウザに保存。
- 習得は語句1問と判断問題2問について、それぞれ10分以上空けた2回の正解が必要。単なる出題経験では習得扱いにしない。これは試験得点の保証ではない。
- 旧保存キーは読み込まず、そのまま保存。新キーは `seikei-midterm-202610-v1`。同じ端末でも別ブラウザへ進捗は自動同期しない。

### ローカル起動・再生成・検証

`file://` で開かず、このフォルダーで `python -m http.server 8769 --bind 127.0.0.1` を実行し、`http://127.0.0.1:8769/` を開いてください。公開環境はHTTPSで使用します。初回オンライン読込でオフライン準備ができた表示を確認してください。

問題データの編集元は `scripts/build_content.py`、印刷教材は `scripts/build_print.py`。再生成は `python scripts/build_content.py` → `python scripts/build_print.py`。180問対応表の再生成には、非公開の `private/政経_問題集180問_出版社解答照合済み.json` が必要です。公開済みの対応表はそのJSONを配布しなくても閲覧・検査できます。

`npm test` はNode標準テストだけで実行できます。`npm install` と `npx playwright install chromium` 後、HTTPサーバー起動中に `npm run test:browser` でブラウザ統合テストとPDF出力を行います。この作業環境ではバンドル済みPlaywrightとEdgeを使用しました。ブラウザテストは専用の一時プロファイルを使い、実際の利用者の進捗を操作しません。

教材・シェル・JSのいずれかを公開更新する場合、`service-worker.js` のキャッシュ名を必ず更新します。キャッシュの切り替えは一式の取得後に行い、他アプリのキャッシュは削除しません。問題IDを意味が変わる形で再利用しないでください。

### 公開について

学校配布のプリント・問題集・過去問・音声の原本は公開リポジトリへアップロードしません。新しい学習データは独自に構成した短い設問と解説で管理し、出典は資料番号・ページ・項目を参照します。

原本は `private/` に置き、`.gitignore` で保護します。公開するのは独自教材・監査表・コード・この教材から生成したPDFだけです。出版社照合済みJSON・訂正報告の原ファイルも公開コミットしません。
