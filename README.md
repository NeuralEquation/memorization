## 演習と進捗

1問1答68問、通常4択32問、複数文の正誤組合せ83問、正誤＋訂正32問、比較・資料読解7問、計算8問、時系列8問、計238問。独自の得票表、財政表、折線・議席図で制度の適用も練習します。回答前に答え・解説・根拠を表示せず、解答後は各文と全選択肢の理由を確認できます。

間違いを数問空けて再出題し、新しい内容も混ぜます。単元、重要度、弱点、全範囲復習、50問演習を利用できます。「未習得優先」は条件内の未習得を先に出し、なくなれば習得済みの復習へ切り替え、その状態を表示します。

各問題の習得は10分以上空けた2回以上の正解と連続正解が条件です。追加36単元の目標習得には語句と指定判断問題の全問（資料読解も含む）が必要です。旧32単元は語句と異なる判断問題2問が条件。出題経験や語句だけで目標習得とはしません。

進捗はブラウザ内に保存され、別の端末へ自動同期しません。「進捗のバックアップ」でJSONを書き出し、「進捗JSONを読み込む」で検査・プレビュー後に適用してください。適用前の進捗を退避し、「復元前に戻す」で戻せます。壊れたJSON、別試験の版、未知のID、回数が矛盾する履歴は受け付けません。旧108問版のID・保存キー・採点基準を維持して、その進捗も読み込めます。前の1学期期末キーとは混在しません。

## 開発・再生成・テスト

`file://`を使わず、リポジトリ内で`python -m http.server 8769 --bind 127.0.0.1`を起動し、`http://127.0.0.1:8769/`を開いてください。公開はHTTPSです。初回オンラインで「オフライン学習の準備ができました」を確認すると、演習・全教材HTML・短縮HTML・監査表をオフラインで使用できます。PDFは端末に保存して利用してください。

データの編集元は`scripts/build_content.py`と`scripts/audited_material.py`。再生成は順に`python scripts/build_content.py`、`python scripts/build_print.py`、`python scripts/build_short.py`。監査表の再生成には`private/政経_問題集180問_出版社解答照合済み.json`が必要です。公開済みデータの利用・テストには不要です。

`npm test`はNode標準テスト15件。`npm install`、`npx playwright install chromium`後、HTTPサーバー起動中に`npm run test:browser`でブラウザ検査15件を実行します。バンドル済みPlaywright・Edgeも使用可能。旧版移行テストでは履歴上のコミット`ffc5496`を参照するため、そのコミットを取得しておいてください。隔離した一時プロファイルを使用し、利用者の進捗は操作しません。

PDF出力はHTTPサーバー起動中に`node scripts/export_pdf.cjs`。旧60ページPDFを上書きせず、新しい2冊を出力します。`python scripts/check_pdf.py`（PyMuPDF・Pillow）は全ページ描画、A4、空白・ページ外文字、問題ID、旧PDFハッシュを検査します。目視点検を省略する代替にはなりません。

教材やコードを公開更新する際は`service-worker.js`のキャッシュ名を更新してください。新しい一式の取得後に切り替え、無関係なキャッシュは保持します。今回のキャッシュは`seikei-midterm-202610-4`、進捗キーは`seikei-midterm-202610-v1`です。意味を変えた問題IDの再利用は避けてください。
