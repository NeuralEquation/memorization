# 政経 定期試験対策アプリ

## 2026年10月：2学期中間試験向けへ移行中

**注意：公開中のアプリの問題データは、現在まだ旧1学期期末版です。10月の試験範囲の完成版ではありません。**

新試験版へ移す実装指示は [CODEX_TASK_2026-10.md](./CODEX_TASK_2026-10.md) および [Issue #1](https://github.com/NeuralEquation/memorization/issues/1) にまとめました。

### 新版の方針

- 授業プリント1〜9を先行して、重要事項・制度比較・数字や条件・正誤判定を練習できる教材にする
- プリント10は試験範囲の確認が取れるまで暫定扱い
- 問題集の指定範囲が届いたら、対応する学習目標と出題を追加して網羅性を点検する
- 要点を整理した印刷用プリントと、アプリの1問1答・正誤仕分けを併用する
- 進捗・弱点復習・スマホ表示・オフライン対応は維持する

### 公開について

学校配布のプリント・問題集・過去問・音声の原本は公開リポジトリへアップロードしません。新しい学習データは独自に構成した短い設問と解説で管理し、出典は資料番号・ページ・項目を参照します。

現在の旧期末教材を使う場合は、**新試験の範囲と取り違えないよう注意してください**。
