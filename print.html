政治制度

政治制度は「誰が行政を担当するか」「議会とどう責任を取り合うか」で考えます。共和制・君主制という元首の分類と、議院内閣制・大統領制という執政の分類は別です。

着眼点議院内閣制米国型大統領制
存立の根拠議会の信任議会とは別に選ばれる大統領
不信任内閣の存立に影響通常の不信任制度はない
解散制度上認められ得る大統領は議会を解散しない

S01 連邦制と単一制

連邦制は連邦と州などが憲法に基づいて権限を分ける仕組み。単一制でも地方自治は存在するが、連邦制と同じ権限構成ではない。地方政府があるだけで連邦制とは判断できない。

確認根拠：プリント1 p1 国家の構成

S02 議院内閣制と大統領制

議院内閣制では内閣は議会の信任に基づき、議会に責任を負う。米国型大統領制では大統領と議会が別々の選挙で正統性を持ち、議会の通常の不信任で大統領は失職しない。弾劾は不信任とは違う。国名ではなく権力間の関係で区別する。

確認根拠：プリント1 p1 執政制度

憲法・人権

憲法は国家の権力を制限し、人権を保障する基礎です。制度の比較では主権の所在を、改正では分母と手続を確認しましょう。家族法の問題は出題の基準日を先に確かめます。

区別判断の基準混同注意
自由権／社会権不当な介入からの自由／生活保障等のための積極的役割信教は自由権、生存は社会権
婚姻時の氏／再婚禁止期間民法750条／旧733条夫婦の氏と待機期間は別問題
2016年／2024年100日へ短縮／再婚禁止期間の廃止昔の判例を現在の規則にしない
改正発議／国民投票各院の総議員の2/3以上／有効投票総数の過半数出席者・有権者総数を分母にしない

S03 明治憲法と日本国憲法

明治憲法では天皇が統治権を総攬し、臣民の権利には法律の留保があった。日本国憲法では国民主権の下で国会・内閣・裁判所に立法・行政・司法を分ける。天皇は象徴であり国政に関する権能を持たない。現行の「全体の奉仕者」を明治憲法の規定にしない。

確認根拠：プリント3 p1 大日本帝国憲法／e-Gov 日本国憲法1・41・65・76条

S04 憲法改正の二段階

憲法改正は各議院の総議員の3分の2以上の賛成による国会の発議と、国民投票の過半数の賛成が必要。国会では「出席議員」でなく「総議員」が分母。国民投票は有効投票総数が分母で、有権者全員の過半数ではない。成立した改正は天皇が国民の名で公布する。

確認根拠：プリント3 p1 改正要件／e-Gov 日本国憲法96条

S05 社会権と自由権

自由権は国家の不当な介入から個人の自由を守る権利。社会権は人間らしい生活を支えるため国家の積極的な役割を求める権利。生存権・教育を受ける権利・勤労の権利・労働基本権を社会権として整理する。信教の自由は精神的自由権である。

確認根拠：訂正報告 p40 Q22／e-Gov 日本国憲法20・25・26・27・28条

S06 婚姻と法改正の時点

民法750条の法律婚では婚姻時に夫または妻の氏を選ぶ。選択的夫婦別氏がすでに一般に導入済みとする説明は採用しない。女性の再婚禁止期間は2016年に6か月から100日へ短縮され、2024年4月1日に廃止された。昔の判例問題では当時の制度を、現行法の問いでは廃止後の制度を用いる。

確認根拠：訂正報告 p38 Q8・p43 Q4-3／e-Gov 民法733・750条／法務省 親子法制改正

S07 父母両系血統主義

国籍法2条1号では、出生時に父または母が日本国民であることを日本国籍取得の条件とする。父だけに限定しないため父母両系血統主義と呼ぶ。日本国内に生まれたという場所だけで、全員が自動的に日本国籍を得る制度でもない。1985年施行の改正を女子差別撤廃条約への対応の論点として整理する。

確認根拠：訂正報告 p43 Q4-3／e-Gov 国籍法2条1号

国会・内閣

国民が議員を選ぶ→国会が総理を指名する→総理が国務大臣を任命する、というつながりを先に理解します。議決条件の違いは、何を決めるのかによって整理します。

制度数・割合条件・例外
本会議の定足数総議員の1/3以上通常の議決は出席者の過半数
法律案の再可決衆議院出席議員の2/3以上参議院の60日不議決は自動成立ではない
予算・条約の優越参議院の不議決30日休会中を除く。両院不一致には協議会の手続
首相指名の優越参議院の不議決10日法律案の再可決要件を当てはめない

国務大臣過半数は国会議員、全員は文民総理は国会が指名し天皇が任命

S08 国会の会期と召集

常会は毎年1回召集され、通常の会期は150日。臨時会は内閣が必要と判断した場合に召集し、いずれかの院の総議員の4分の1以上から要求があれば内閣に召集義務がある。特別会は衆議院解散による総選挙後30日以内に召集する。衆議院の任期満了選挙後を特別会としない。

確認根拠：プリント4 p1 国会の種類／e-Gov 日本国憲法52〜54条

S09 定足数と議決の分母

本会議は総議員の3分の1以上が出席しなければ開議・議決できない。通常の議事は出席議員の過半数で決する。可否同数なら議長が決する。会議を成立させる人数と、成立した会議で議案を可決する人数は別の条件である。

確認根拠：プリント4 p1 本会議／e-Gov 日本国憲法56条

S10 法律案と衆議院の優越

法律案は原則として両院で可決する。参議院が異なる議決をした場合、衆議院は出席議員の3分の2以上で再可決できる。参議院が受領後60日以内に議決しない場合、衆議院は否決したとみなすことができる。60日で自動的に法律になるわけではない。休会中はこの期間に算入しない。

確認根拠：プリント4 p1 法律案／e-Gov 日本国憲法59条

S11 予算・条約・首相指名の優越

予算と条約承認では両院の議決が異なり、両院協議会でも一致しないとき、衆議院の議決が国会の議決になる。参議院が受領後30日以内に議決しない場合も同様。首相指名では10日。いずれも休会中を除く。法律案のような3分の2での再可決を要しない。予算は衆議院先議である。

確認根拠：プリント4 p1 予算・条約・首相指名／e-Gov 日本国憲法60・61・67条

S12 全国民の代表と議員特権

国会議員は全国民の代表であり、地方議員のような住民によるリコール制度はない。不逮捕特権は原則として会期中の保障で、院の許諾や院外の現行犯罪などの例外がある。免責特権は院内の演説・討論・表決について院外で責任を問われない保障であり、あらゆる犯罪の免責ではない。

確認根拠：訂正報告 p51 Q7／プリント4 p1／e-Gov 日本国憲法43・50・51条、国会法33条

S13 内閣の組織と文民

内閣総理大臣は国会議員の中から国会が指名し、天皇が任命する。国務大臣は総理が任命し、その過半数は国会議員から選ぶ。全員が国会議員である必要はないが、総理と国務大臣は全員文民でなければならない。内閣は国会に対し連帯して責任を負う。

確認根拠：プリント5 p1 組織／e-Gov 日本国憲法66〜68条

S14 不信任と総辞職

衆議院で内閣不信任が可決、または信任が否決されたら、内閣は10日以内に衆議院を解散しない限り総辞職する。参議院の問責決議には同じ法的効果がない。総理の欠缺や、衆議院総選挙後初めての国会召集でも内閣は総辞職する。総辞職後は新総理任命まで職務を継続する。

確認根拠：プリント5 p1 交代／e-Gov 日本国憲法69〜71条

S15 内閣と国会の職務分担

内閣は法律を執行し、予算案を作成して国会に提出し、条約を締結する。国会は予算を議決し、条約を承認する。内閣の政令は法律の実施等のために制定するもので、法律の委任なしに罰則を設けることはできない。政策を実施する機関と決定・承認する機関を分けて覚える。

確認根拠：プリント5 p1 職務権限／e-Gov 日本国憲法73条

地方自治

地方では首長も議会も住民が選びます。そのため内閣と国会の関係をそのまま移してはいけません。直接請求は「署名」「請求先」「最終決定方法」の三点で比較します。

S16 住民自治と団体自治

住民自治は地域の住民が地域政治に参加して決める原理。団体自治は国から独立した地方公共団体が自主的に事務を処理する原理。首長と地方議会議員を住民が直接選ぶ二元代表制は議院内閣制とは異なる。条例制定は法律の範囲内で認められる。

確認根拠：プリント6 p1 原則・機関／e-Gov 日本国憲法92〜94条

S17 条例請求と監査請求

条例の制定・改廃の直接請求は有権者の50分の1以上の署名で首長へ、事務の監査の直接請求は同じ割合で監査委員へ行う。地方税の賦課徴収等の条例は74条の請求対象から除かれる。条例請求は議会に付議され、署名が集まっただけで成立しない。住民監査請求の別制度と混同しない。

確認根拠：プリント6 p1 直接請求／e-Gov 地方自治法74・75条

S18 解散・解職の段階署名数

議会解散や議員・首長の解職請求では、有権者40万人までは3分の1。40万人を超え80万人以下なら40万÷3＋超過分÷6。80万人超なら40万÷3＋40万÷6＋80万人超の部分÷8。対象は人口ではなく有権者総数。端数を途中で丸めず最後に切り上げる。請求先は選挙管理委員会で、その後の投票と署名要件は別である。

確認根拠：プリント6 p1／訂正報告 p49／e-Gov 地方自治法76・80・81条

S19 副知事等の解職手続

副知事・副市町村長等の解職も、必要な署名を集めて請求できる。請求先は首長であり、議会に付議する。議員の3分の2以上が出席し、その出席者の4分の3以上が同意すれば失職する。住民が直接選んだ首長や議員の解職請求と、請求先・最終決定方法が異なる。署名数は段階計算の対象である。

確認根拠：訂正報告 p74 Q7／プリント6 p1／e-Gov 地方自治法86・87条

S20 自治事務と法定受託事務

自治事務は地方公共団体が処理する事務のうち法定受託事務以外。法定受託事務は、国等が本来果たす役割に関わり、適正な処理を確保する必要があるものとして法令で特に定める事務。どちらも地方公共団体が処理する。憲法が個別事務を全て列挙するわけではなく、国の関与も無制限ではない。

確認根拠：訂正報告 p61 地方10／プリント6 p1／e-Gov 地方自治法2条8・9項

S21 地方交付税と国庫支出金

地方税収には地域差があり、そのままでは提供できる行政サービスに格差が生じる。地方交付税は財源の均衡化等のため国税の一定割合等を財源に交付し、国が使途を制限してはならない。国庫支出金は特定事業の財源で使途が特定される。「国から来る財源」は共通でも、自由に使えるかが異なる。

確認根拠：訂正報告 p60 地方8／e-Gov 地方交付税法1〜3条

司法

裁判は法に基づいて紛争を解決し、権利を守る仕組みです。捜査→起訴するかの判断→第一審→不服申立て→確定、という順に、各制度が働く段階を位置付けます。

区別前者後者
最高裁長官／総理の指名内閣が指名国会が指名
控訴・上告／再審通常の不服申立て確定判決後に法定の理由でやり直し
裁判員／検察審査会対象刑事裁判の第一審不起訴処分の審査
違憲審査の権限／終審下級裁判所も持つ最高裁判所
消極主義／審査権なし行使に慎重という立場権限自体の否定。両者は違う

S22 裁判官の独立と任命

裁判官は良心に従い独立して職権を行い、憲法と法律にのみ拘束される。最高裁長官は内閣が指名し天皇が任命、他の最高裁裁判官は内閣が任命する。下級裁判所裁判官は最高裁が指名した名簿に基づき内閣が任命する。国民審査は最高裁裁判官が対象で、全裁判官の選挙ではない。

確認根拠：プリント7 p1 裁判官／e-Gov 日本国憲法76・78〜80条

S23 控訴・上告・再審

控訴は第一審判決に対して上級裁判所の判断を求め、上告は第二審判決等に対してさらに上級裁判所の判断を求める。三審制は審理を必ず3回行う意味ではない。再審は確定判決に対し一定の理由がある場合に審理をやり直す特別の手続で、通常の第三審ではない。

確認根拠：プリント7 p1 裁判のしくみ

S24 裁判員と検察審査会

裁判員は一定の重大な刑事事件の第一審で裁判官とともに有罪・無罪や量刑を判断する。検察審査会は検察官の不起訴処分の当否を審査し、一定の二度の起訴議決によって指定弁護士が起訴する場合がある。不起訴を審査することと、刑事裁判で有罪を決めることは別の段階である。

確認根拠：プリント7 p1 国民の司法参加

S25 刑事手続と人権

逮捕には原則として裁判官の令状が必要で、現行犯逮捕は例外。自白だけが唯一の証拠なら有罪にできず、強制された自白には証拠能力がない。黙秘権は自己に不利益な供述を強制されない保障。刑罰の不遡及と一事不再理は、後からの処罰や同じ事件の繰り返しの訴追から個人を守る。

確認根拠：プリント8 p1 刑事手続／e-Gov 日本国憲法33〜40条

S26 付随的違憲審査

日本では具体的な事件の解決に必要な範囲で違憲審査をする付随的審査制を採る。下級裁判所も違憲審査を行い、最高裁は終審裁判所である。法律が疑わしいだけで事件と無関係に抽象的な審査をする制度とは異なる。憲法に反する法令等は憲法98条により効力を持たない。

確認根拠：プリント8 p1 違憲審査／e-Gov 日本国憲法81・98条

S27 司法消極主義の根拠

国会は選挙された議員で構成され民主的な正統性を持つ。この点から、選挙を直接の基盤としない裁判所が国会の判断を広く覆すことに慎重であるべきだとする考えが司法消極主義の根拠となる。裁判所に違憲審査権がないという意味ではない。司法積極主義は人権保障等を重視して審査に積極的な立場である。

確認根拠：訂正報告 p58 Q17／プリント8 p1 司法と民主主義
